# レビュー禁止事項
かつて以下のようなレビューが来た

```
巨大画像の制限が、デコード後にしか効かない
PNG/JPEG/WebPは、まず createImageBitmap(file) で画像をデコードし、そのあと寸法を検査している。
しかも現在の検査は縦横それぞれ16384pxまで許可し、テストでも16384×16384を正常扱いしている。これは素のRGBAだけで約1GiB。bitmap、Canvas、履歴用コピーなどが重なると数GiB級になりうる。
ここは、
- デコード前にPNG/JPEG/WebPのヘッダーから寸法を読む
- 一辺だけでなく width × height × 4 でも上限判定
- 履歴や変換時の一時コピーを含むピークメモリで制限する
- デコード前にPNG/JPEG/WebPのヘッダーから寸法を読む
- 辺だけでなく width × height × 4 でも上限判定
- 履歴や変換時の一時コピーを含むピークメモリで制限する
までやりたい。いま一番クラッシュへ直結しそうなのはここ。
```
しかし、16384×16384は仕様に明記されているし由来のある値である。そのため今後は16384pxという仕様への変更提案そのものを禁止とする。
また、このドキュメント自体もレビュー禁止。
