# 重い操作中の排他仕様

保存、描画、AI 送信、タブ閉じ、PSD 読み込み、自動バックアップは、同じ
`PaintDocument`、`History`、tab store、保存済み version marker を触るため、同時実行の
可否をここで固定する。

UI の `disabled` や overlay は補助であり、実際の拒否は action handler または controller
で行う。新しい入口を追加した場合も、この表に従って同じ busy state を参照する。

## Busy state の定義

- 保存中: `useFileActions` の `savingRef.current === true`。
- 描画中: Canvas が共有する `paintBusyRef.current === true`。ブラシなどの pointer
  session 開始から終了までを指す。
- AI 送信中: AI 解析、比較、課題採点のいずれかが進行中。
  実装上は `ai.isLoading || ai.isChallengeScoring`。
- チャット送信中: `chat.anyChatLoading` が `true` の期間。現在タブの
  `chat.chatLoading` と背景タブの `tab.uiState.chatLoading` を集約し、どこか1タブでも
  送信中なら新規キャンバス、タブ操作、バックアップ開始・新しいタブへの復元、
  AI 送信開始を禁止する。
  背景タブの送信完了も通知して判定を更新する。
- タブ閉じ中: タブ閉じ要求を受けてから、未保存確認と `tabStore.closeTab()` が完了
  するまで。
- PSD 読み込み中: Tauri ではネイティブファイル選択ダイアログを開く直前から、選択の
  キャンセルまたは読み込み workflow の完了までを指す。`.psd` の読み込み workflow が
  新規 tab を作成し、`loadPsd()` と初回 paint 待ちを完了するまで、ならびにファイル
  読み込み overlay が出ている通常の読み込みも同じ扱いにする。
- バックアップ中: `AutoBackupRunner` が開始時のアクティブタブを保存している期間。
  `isBusy()` はこの保存処理が進行中かを表す。

ファイル読み込み中はキーボードショートカットを一括して止める。AI 処理中または
チャット送信中は一括して止めず、`Ctrl+O`、`Ctrl+S` も通常どおり処理する。

## 許可/禁止表

`禁止` は「要求を受けても開始しない」ことを表す。自動バックアップだけはユーザー操作
ではないため、禁止時は toast ではなく静かにスキップしてよい。

| 実行中の操作 | 保存開始 | 描画/編集開始 | AI 送信開始 | タブ切替 | タブ閉じ | PSD/ファイル読み込み | 自動バックアップ開始 | 表示だけの操作 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 保存中 | 禁止 | 禁止 | 禁止 | 禁止 | 禁止 | 禁止 | 禁止 | 許可 |
| 描画中 | 禁止 | 禁止 | 禁止 | 禁止 | 禁止 | 禁止 | 禁止 | 許可 |
| AI 送信中 | 許可 | 禁止 | 禁止 | 許可 | 禁止 | 許可 | 禁止 | 許可 |
| チャット送信中 | 許可 | 許可 | 禁止 | 禁止 | 禁止 | 許可 | 禁止 | 許可 |
| タブ閉じ中 | 禁止 | 禁止 | 禁止 | 禁止 | 禁止 | 禁止 | 禁止 | 許可 |
| PSD/ファイル読み込み中 | 禁止 | 禁止 | 禁止 | 禁止 | 禁止 | 禁止 | 禁止 | 許可 |
| バックアップ中 | 禁止 | 禁止 | 禁止 | 禁止 | 禁止 | 禁止 | 禁止 | 許可 |

表示だけの操作は、ドキュメント、履歴、レイヤー、tab store、保存済み version marker を
変更しない操作に限る。例: zoom、pan、回転表示、左右反転表示、テーマ切替、ガイド表示の
開閉。レイヤー順、選択範囲、テキスト、色調補正、キャンバス拡張、読み込み、保存先変更は
表示だけではない。

## 実装上の原則

- 保存は開始時の `History` snapshot と `PaintDocument` snapshot を保存完了判定に使う。
  await 中に変更が入った場合、保存先情報だけ更新し、`lastSavedVersion` は進めない。
- 描画/編集ツールは `paintBusyRef`、AI 送信中判定、`AutoBackupRunner.isOperationBusy()` を見る。
  自動バックアップの `saveAiPaint()` 中にピクセルを書き換えると、途中状態の PNG が
  保存される可能性がある。
- 新規キャンバスはダイアログを開く時と作成確定時の両方で、AI 送信中と
  全タブのチャット送信中を確認する。ファイル読み込みによるタブ追加は表の許可を維持する。
- AI 送信は送信対象画像とレスポンス適用先 tab を開始時に固定する。完了前の tab 切替は
  許可するが、tab 集合やドキュメント構造が変わる操作は開始しない。
- PSD 読み込みは一時 tab を作り、失敗時に閉じる。読み込み中に別の tab 操作や保存を
  走らせない。Tauri のネイティブファイル選択はダイアログを開く直前に読み込み中へ
  遷移する。すでにバックアップ中ならダイアログを開かず、先に開始した操作を優先する。
- タブ閉じは未保存確認を含めて排他対象にする。確認ダイアログが OS 側の場合でも、内部
  的には busy として扱う。
- 自動バックアップは低優先度の操作とする。各 tick とタブ切替後に、その時点の
  アクティブタブだけを確認し、変更があれば1件保存する。非アクティブタブは監視せず、
  待機キューにも入れない。保存中、描画中、AI 送信中、チャット送信中、PSD/ファイル
  読み込み中は新しいバックアップを開始しない。
- バックアップパネルの復元、削除、整理は `useAutoBackupController` を必ず経由する。
  これらは `AutoBackupRunner.runMutation()` で現在の保存処理と直列化する。パネルの
  `disabled` は controller と同じ gate 判定を表示するだけで、排他の正本にはしない。
- バックアップ開始後は対象を切り替えない。完了まではタブ切替、追加、閉じる、並べ替えを
  すべて禁止し、ファイル読み込みや描画も開始しない。

## 作業Agentと共通API

- Agentは右パネルに表示する。パネルを開くだけでは通常編集を止めない。制作中・操作の完了待ち・制作記録の再生表示中は編集UIとショートカットを止め、キャンバスのパン・ズームとAgentの停止操作を残す。「現在の絵に戻る」で再生による編集ロックを解除する。実行中は外部APIからの編集も拒否する。
- Agentは開始時のドキュメントと読込世代を保持する。対象が変わった場合や停止後の遅延応答は適用しない。
- 共通APIは読取・変更を直列化する。変更開始時に保存・読込・描画・バックアップのbusyを確認し、描画/レイヤー/選択/キャンバス/履歴操作とファイル読込の間は `paintBusyRef` を保持する。外部APIからの変更中も通常画面を `inert` にする。
- ファイル保存とデータ書出しは `savingRef`、バックアップ操作は既存controllerの排他を使う。Agentのモデル応答待ちにはバックアップできるが、APIがピクセルを更新している間は開始しない。
- Agent実行中のタブ変更・ファイル読込・バックアップ復元はAPI handlerでも拒否する。制作を一時停止してから行う。

## 変更時の確認

重い操作の入口を追加・変更した場合は、次を確認する。

- action handler とショートカット handler の両方で同じ禁止条件を見る。
- UI の `disabled` だけに依存していない。
- async 完了後に更新する tab / document が開始時と同じか確認している。
- この表のどの行・列に該当するかを更新している。
